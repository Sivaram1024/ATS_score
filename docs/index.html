    Local Setup

    Run the Full Python Backend Locally

    To run with live PDF file uploading, local Sentence-BERT embeddings, and full Gemini API connectivity: 

    # 1. Clone repository
git clone https://github.com/Sivaram1024/ATS_score.git
cd ATS_score

# 2. Setup Virtual Environment
python -m venv .venv
.venv\Scripts\activate   # Windows
source .venv/bin/activate # Linux/Mac

# 3. Install Dependencies
pip install -r requirements.txt

# 4. Configure .env with your Gemini API Key
copy .env.example .env
# Edit .env and set GEMINI_API_KEY=your_key

# 5. Run the Flask Server
python app.py

# Open browser at http://localhost:5000
